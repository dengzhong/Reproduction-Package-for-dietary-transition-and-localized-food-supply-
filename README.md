# Lower global food system emissions via integrating dietary transition and localized food supply

## Overview

This repository provides the code and supporting materials associated with the research paper **"Lower global food system emissions via integrating dietary transition and localized food supply"**.

The study investigates the climate mitigation potential of integrating localized food supply strategies with dietary transitions. By combining spatial optimization, transportation networks, and greenhouse gas emission accounting, the study evaluates changes in food miles, transport emissions, and agricultural production emissions under alternative food supply and dietary scenarios.

## Code and reproducibility

The research uses R and GAMS for spatial data processing, transportation network analysis, optimization, emissions accounting, and results visualization.

Detailed instructions, software requirements, and descriptions of the input data will be provided alongside the corresponding code files.
